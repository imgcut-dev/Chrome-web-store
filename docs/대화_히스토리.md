### 🤖 Claude

4개 파일을 이 폴더에 만들었습니다. manifest JSON과 JS 문법 검사는 통과했지만, 크롬에 설치해서 동작시켜 보지는 않았습니다.

요청문에 `[1-2 기획서 표를 붙여 넣으세요]`가 그대로 남아 있어서 표 내용은 못 봤습니다. 그래서 이름에 맞춰 아래 기본 기능으로 만들었습니다.
- 드래그한 문장을 우클릭해서 저장
- 팝업에서 목록 보기
- 클릭하면 복사
- ✕로 삭제

표를 붙여 주시면 그 내용에 맞춰 고치겠습니다.

## 각 파일이 하는 일
- [manifest.json](manifest.json): 확장 프로그램의 이름, 권한, 연결할 파일을 적은 설정 파일입니다. Manifest V3이고, 권한은 `contextMenus`와 `storage`만 씁니다.
- [background.js](background.js): 설치될 때 "내 문장 모음에 저장" 우클릭 메뉴를 만듭니다. 텍스트를 선택했을 때만 보입니다. 메뉴를 누르면 선택한 문장을 `chrome.storage.local`에 저장하고, 이미 있는 문장은 다시 저장하지 않습니다.
- [popup.html](popup.html): 아이콘을 눌렀을 때 뜨는 창의 모양입니다.
- [popup.js](popup.js): 저장된 문장을 목록으로 보여 주고, 문장을 클릭하면 복사하며, ✕를 누르면 삭제합니다.

외부 라이브러리와 바깥 서버 요청은 없습니다.

## 크롬에 설치하는 순서
1. 크롬 주소창에 `chrome://extensions`를 입력합니다.
2. 오른쪽 위 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다**를 누릅니다.
4. 이 폴더(`04 Chrome webstore`)를 선택합니다.
5. 아무 웹페이지에서 문장을 드래그하고 우클릭해서 **내 문장 모음에 저장**을 누릅니다.
6. 툴바의 확장 프로그램 아이콘(퍼즐 모양)을 눌러 팝업을 열면 저장된 문장이 보입니다.

코드를 고친 뒤에는 `chrome://extensions`에서 이 확장 프로그램 카드의 새로고침 버튼을 누르면 반영됩니다.

바뀐 이름을 적용하려면 `chrome://extensions`에서 이 확장 프로그램 카드의 새로고침 버튼을 누르세요. 그다음 열려 있던 웹페이지도 새로고침하면 됩니다.

링크 위에서도 항목이 보이게 하려면 말씀해 주세요. 그 경우 링크의 글자나 주소를 저장하도록 로직을 따로 정해야 합니다.

## 확인할 점
- **`chrome://` 페이지, 새 탭 화면, 크롬 웹스토어**에서는 확장 프로그램이 막혀 있어서 메뉴가 안 나올 수 있습니다. 일반 `https://` 사이트에서 하세요.
- **오류가 나면** `chrome://extensions`의 카드에서 **서비스 워커**를 눌러 콘솔 오류를 보거나, 팝업을 우클릭해 **검사**를 누르세요.
- **저장된 데이터를 지우려면** 팝업에서 삭제를 누르거나, 확장 프로그램을 제거했다가 다시 로드하세요.

## 카테고리 자동 만들기
저장한 문장의 웹사이트 도메인을 그대로 카테고리로 씁니다. 예를 들어 `brunch.co.kr`, `medium.com`이 각각 카테고리가 됩니다. 페이지 내용을 읽거나 서버에 물어보면 권한이 더 필요한데, 권한과 서버 요청을 쓰지 않기로 했기 때문입니다. "뉴스", "개발"처럼 주제별로 묶으려면 사이트별 분류표를 직접 정해 두는 방식이 필요합니다.

## 팝업 사용법
- **왼쪽 카테고리 메뉴**: 헤더 왼쪽 ☰를 누르면 카테고리 목록이 왼쪽에서 열립니다. "전체"와 사이트별 개수가 나오고, 항목을 누르면 그 사이트의 문장만 보입니다. 이전에 문자열로만 저장한 문장은 "기타"로 묶입니다.
- **달력**: 헤더 오른쪽 달력 아이콘을 누르면 월 달력이 펼쳐집니다. 문장을 저장한 날에는 점이 찍히고, 날짜를 누르면 그날 저장한 문장만 보입니다. 달력은 ‹ ›로 달을 넘길 수 있습니다.
- **필터 해제**: 선택한 카테고리와 날짜는 목록 위에 표시됩니다. 누르면 해제됩니다.

코드는 [popup.html](popup.html)과 [popup.js](popup.js)에 있습니다. `chrome://extensions`에서 이 확장 프로그램 카드의 새로고침 버튼을 누르면 적용됩니다.

### 🤖 Claude

원문 주소가 `http`/`https`가 아니라서 새 창 대신 복사로 동작합니다. 시크릿 창의 기본 페이지는 인터넷 페이지가 아니라 크롬 내부 페이지(`chrome://newtab/`)입니다. 카드 맨 위 사이트 이름이 `newtab`으로 나오는 것도 그 주소의 이름 부분이 그대로 표시된 것입니다.

[popup.js](popup.js)는 카드를 눌렀을 때 주소가 `http`/`https`일 때만 원문을 새 탭으로 열고 문장에 하이라이트를 줍니다. 그 외 주소는 열 곳이 없다고 보고 문장을 복사하고 "복사됨!"만 보여 줍니다.

이렇게 만든 이유는 두 가지입니다.
- 확장 프로그램이 만든 링크로는 `chrome://` 페이지를 열 수 없습니다.
- 열더라도 `chrome://` 페이지에는 저장한 문장을 하이라이트하는 기능이 통하지 않습니다.

그래서 문장은 정상적으로 저장됐고, 카드를 눌렀을 때 복사로 동작하는 것은 의도된 동작입니다. 다만 "복사됨!"만 뜨면 고장처럼 보이므로 개선하는 편이 좋겠습니다.

- 이런 카드에서는 토스트를 "원문 페이지가 없어 문장을 복사했어요"로 바꿉니다.
- 사이트 이름을 `newtab` 대신 "크롬 내부 페이지"로 표시합니다.

이 개선은 코드에 아직 반영하지 않았습니다. 진행할까요?

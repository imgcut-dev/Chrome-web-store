### 2-2. 자세한 설명 (스토어 상세 페이지)
```
웹에서 마음에 드는 문장, 놓치지 않게 밑줄 노트에 담아 두세요.

■ 이렇게 사용해요
1. 웹페이지에서 저장하고 싶은 문장을 드래그합니다. (이미지는 이미지 위에서 우클릭)
2. 마우스 오른쪽 버튼 → "밑줄 노트"를 누릅니다.
3. 화면에 "메시지가 정상적으로 저장되었습니다."가 나타나면 끝!
4. 툴바의 My 아이콘을 눌러 저장한 내용을 모아 봅니다.

■ 주요 기능
• 우클릭 저장: 문장과 이미지를 한 번에 저장
• 출처 자동 기록: 저장한 페이지 주소, 저장 시각, 페이지 대표 이미지(썸네일)
• 원문으로 이동: 저장한 문장을 누르면 원문 페이지가 열리고 그 문장이 표시됩니다
• 사이트별 분류: 저장한 사이트(예: 네이버 뉴스, GitHub)로 자동 분류, 왼쪽 메뉴에서 선택
• 달력 보기: 날짜마다 저장 개수를 보여 주고, 고른 날의 문장·페이지 수를 요약
• 복사·삭제: 카드에서 바로 복사하거나 삭제
• 표시 방식 선택: 팝업 / 새 창 / 사이드 패널 중 원하는 방식으로 열기 (설정에서 바로 적용, 사이드 패널은 지원하는 브라우저에서 사용 가능)
• 저장 실패 알림: 저장되지 않았을 때는 다시 시도하라는 안내 표시

■ 개인정보
• 저장한 내용은 내 브라우저 안에만 보관되며, 제작자나 외부 서버로 전송하지 않습니다.
• 광고, 추적, 분석 도구를 사용하지 않습니다.
• 저장 시 해당 페이지의 대표 이미지 주소를 읽어 목록에 표시하며, 썸네일은 원래 사이트에서 불러옵니다.

■ 문의
앱 하단의 "E-mail 문의" 또는 "제작자 블로그"를 이용해 주세요.
```

## 5. 개인정보 보호 탭 (심사에서 입력)
- **단일 목적**: 웹페이지에서 선택한 문장·이미지를 저장하고 모아 보는 노트
- **권한 사용 사유**
  | 권한 | 사유 |
  |---|---|
  | `contextMenus` | 우클릭 메뉴 "밑줄 노트" 표시 |
  | `storage` | 저장한 내용과 설정을 브라우저 내부에 보관 |
  | `activeTab` | 저장을 누른 탭에서만 페이지 대표 이미지(og:image)를 읽고 저장 알림 표시 |
  | `scripting` | 위 탭에서 대표 이미지 주소 읽기, 저장 성공/실패 알림 표시 |
  | `sidePanel` | 사용자가 설정에서 선택한 경우 사이드 패널로 표시 |
- **호스트 권한**: 없음
- **원격 코드**: 사용하지 않음
- **데이터 사용**: 저장 내용은 사용자 브라우저에만 저장, 판매·제3자 제공·전송 없음
- **개인정보 처리방침 URL**: 웹 페이지 내용을 저장하므로 입력을 권장합니다. 아직 없습니다 (제작자 블로그에 게시 후 URL 입력)

## 2. Description

### 2-1. Summary (max 132 characters, 108 used)
```
Save sentences and images from any web page with one right-click, then browse them by site or on a calendar.
```

### 2-2. Detailed description
```
Keep the sentences you love from the web. Underline Note saves them with one right-click.

HOW IT WORKS
1. Select a sentence on any web page (for an image, right-click the image).
2. Right-click and choose "Underline Note" (shown as "밑줄 노트" in the menu).
3. A confirmation appears on the page once it is saved.
4. Click the toolbar icon to browse everything you saved.

FEATURES
• Right-click saving: sentences and images in one step
• Automatic source info: page address, save time and the page's preview image
• Jump to the source: click a saved sentence to open the original page at that sentence
• Grouped by site: notes are sorted automatically by the site you saved them from
• Calendar view: see how many notes you saved each day, with a summary for the day you pick
• Copy and delete: right from each card
• Choose how it opens: popup, new window or side panel (changes apply instantly; side panel needs a browser that supports it)
• Save error alert: you are told when something could not be saved

PRIVACY
• Everything you save stays inside your own browser. Nothing is sent to the developer or any server.
• No ads, tracking or analytics.
• When you save, the extension reads the page's preview image address to show a thumbnail; the thumbnail is loaded from the original site.

NOTE
The interface is currently available in Korean only.

CONTACT
Use "E-mail 문의" (email) or "제작자 블로그" (developer's blog) at the bottom of the app.
```

## 4. Permission justifications (English)
| Permission | Justification |
|---|---|
| `contextMenus` | Adds the "Underline Note" item to the right-click menu. |
| `storage` | Stores saved notes and the user's display setting in the browser. |
| `activeTab` | Lets the extension act only on the tab where the user chose to save. |
| `scripting` | Reads the page's preview image address and shows a save success/failure message on that tab. |
| `sidePanel` | Shows the notes in the side panel when the user selects that option in Settings. |

Single purpose: Save sentences and images selected on web pages and browse them later.

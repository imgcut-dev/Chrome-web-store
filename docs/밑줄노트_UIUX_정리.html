1. 서비스 개요

웹페이지에서 문장을 드래그하거나 이미지를 우클릭해 "밑줄 노트" 메뉴를 누르면 저장되고, 툴바 아이콘으로 모아 보는 확장 프로그램입니다.

저장드래그한 문장 또는 우클릭한 이미지를 우클릭 메뉴 밑줄 노트로 저장. 저장 시 출처 URL, 저장 시각, (있으면) 페이지의 OG 대표 이미지를 함께 보관. 같은 문장은 중복 저장하지 않음.
조회툴바 아이콘으로 목록 화면을 엶. 사이트별 분류(왼쪽 햄버거 메뉴)와 달력 보기 제공.
활용카드를 누르면 원문 페이지로 이동하고 저장한 문장이 하이라이트됨(텍스트 프래그먼트). 복사·삭제 버튼 제공.
보관 위치브라우저 내부 저장소(chrome.storage.local). 외부 서버로 보내지 않음.
권한contextMenus(우클릭 메뉴), storage(저장), activeTab·scripting(OG 이미지 읽기, 저장 토스트 표시), sidePanel(사이드 패널)

2. 화면별 기능 설명

스크린샷은 변경된 디자인(화이트 배경, 하단 바 적용)을 400×680 기준으로 캡처한 것입니다. 화면은 소통을 위해 화면명세 번호로 구분합니다.

번호화면번호화면
ma01전체 목록ma05빈 상태
ma02사이트 선택(필터)ts01저장 토스트
ma03햄버거 메뉴st01설정 · 표시 방식
ma04달력

번호 규칙: ma = 메인 화면(목록 영역), ts = 토스트, st = 설정. 뒤 두 자리는 순번.

2-1. 전체 목록 ma01 기본 화면

구성상단 헤더(☰ 메뉴 · My 로고 · 화면 제목 · 저장 개수 · 달력 아이콘), 필터 칩 줄, 저장 카드 목록, 하단 바(가로로 긴 영역. 왼쪽부터 저작권 문구 · E-mail 문의 · 제작자 블로그, 오른쪽 끝에 버전 · 설정 톱니)
카드사이트 이름(링크) → 썸네일 48×48(있을 때) + 본문(최대 3~4줄) → 저장 시각 · 복사 · 삭제(휴지통 아이콘)
동작
  • 본문 클릭: 원문 페이지를 새 탭으로 열고 저장한 문장으로 이동·하이라이트
  • 복사: 문장(이미지만 저장했으면 이미지 주소)을 클립보드에 복사, "복사됨!" 토스트
  • 삭제: 해당 카드만 삭제(최신 저장소 기준이라 다른 문장은 보존)
  • My 로고: 어떤 상태에서든 전체 목록으로 복귀(필터·달력·메뉴 모두 해제)
  • 창을 열어 둔 채 새로 저장해도 목록이 자동 갱신

2-2. 사이트 선택 (필터) ma02

구성헤더 제목이 선택한 사이트 이름으로 바뀜. 헤더 아래 필터 칩(네이버 뉴스 ✕)과 초기화 버튼.
동작
  • 칩의 ✕: 해당 필터만 해제
  • 초기화: 필터가 1개 이상이면 항상 표시. 사이트·날짜 필터를 한 번에 해제
  • 카테고리는 저장한 페이지의 도메인으로 자동 분류하고 잘 알려진 사이트는 이름으로 표시(예: n.news.naver.com → 네이버 뉴스). 같은 이름의 도메인은 하나로 합침

2-3. 햄버거 메뉴 (사이트 카테고리) ma03

구성왼쪽에서 슬라이드로 열리는 220px 패널. "전체" + 사이트별 항목과 저장 개수. 현재 선택 항목은 보라색 강조.
동작항목 선택 시 메뉴가 닫히고 해당 사이트만 표시. 바깥(어두운 영역) 클릭으로 닫기.

2-4. 달력 ma04

구성제목 "달력", 월 이동(‹ ›), 날짜 격자, 하단 요약. 달력 화면에서는 헤더 아이콘이 목록 아이콘으로 바뀌어 목록으로 돌아올 수 있음.
날짜 셀저장한 글이 있는 날은 날짜 아래에 저장 개수를 작게 표시. 선택한 날은 보라색 배경, 오늘은 테두리.
동작
  • 달력을 열면 오늘 날짜가 자동 선택되어 오늘 저장한 글이 아래에 바로 보임
  • 하단 요약: 2026.11.19 · 문장 3개 · 페이지 2개 (페이지는 서로 다른 URL 기준)
  • 날짜 칩의 ✕ 또는 초기화로 날짜 선택 해제

2-5. 빈 상태 ma05 V1.2.0 적용

구성저장된 글이 없을 때 목록 대신 안내 문구 표시: "저장된 문장이 없어요 / 웹페이지에서 문장을 드래그하거나 이미지를 우클릭 → "밑줄 노트"를 눌러 보세요."
현황시안과 같이 가운데 정렬, 따옴표 아이콘 + 제목 + 안내 문구로 표시하도록 적용. 필터·날짜 때문에 결과가 없을 때는 한 줄 안내만 표시.

2-6. 저장 토스트 (웹페이지 위) ts01 신규

위치사용자가 보고 있는 웹페이지 상단 가운데에 2.5초간 표시(밑줄 노트 창이 아님)
성공보라색 · "메시지가 정상적으로 저장되었습니다."
실패빨간색 · "메시지를 저장하지 못했습니다. 다시 시도해주세요"
예외chrome:// 같은 확장 프로그램이 접근할 수 없는 페이지에서는 토스트가 뜨지 않음(저장은 정상). 이미 저장된 문장을 다시 저장해도 성공 토스트가 뜸.

2-7. 설정 · 표시 방식 st01 신규

진입화면 아래 하단 바의 오른쪽, 버전(V1.2.4) 옆 톱니 버튼
구성"표시 방식" 라디오 3개(팝업 · 새 창 · 사이드 패널). 각 항목 오른쪽 끝에 모양을 보여 주는 아이콘 그림(툴바 아래 팝업 / 겹친 창 / 오른쪽 패널)을 두어 처음 보는 사람도 차이를 알 수 있게 함. 하단에 안내 박스 "선택하면 별도의 저장 없이 바로 저장되고, 다음에 아이콘을 누를 때부터 적용됩니다."
동작선택 즉시 저장(별도 저장 버튼 없음), "선택 완료 · 저장 없이 적용돼요" 토스트. 사이드 패널을 지원하지 않는 브라우저에서는 해당 항목을 회색으로 비활성화하고 새 창으로 대신 엶.

4. 표시 방식 (팝업 · 새 창 · 사이드 패널)

방식모습장점단점
팝업툴바 아이콘 아래에 붙음가볍고 익숙함바깥을 누르면 닫힘, 높이 최대 600px
새 창 기본독립된 창이동·크기 조절 가능, 직접 닫기 전까지 유지, 위치·크기 기억별도 창이 하나 더 생김
사이드 패널화면 오른쪽에 붙고 페이지를 옆으로 밂페이지와 나란히 보며 작업브라우저가 지원해야 함(미지원 시 비활성)

5. UI/UX 개선 이력

피드백/문제개선 내용
창이 짧아 목록이 답답함창 높이를 680으로 확대
어떤 사이트 글인지 모름카드 상단에 사이트 이름 표기
삭제 버튼이 텍스트휴지통 아이콘으로 교체
저장한 글을 누르면 원문으로 가고 싶음텍스트 프래그먼트로 원문 이동 + 문장 하이라이트
이미지 저장 글이 구분되지 않음OG/선택 이미지를 48×48 썸네일로 표시 (권한 확대 승인 후 적용)
다른 창을 열면 노트 창이 닫힘팝업을 독립 창으로 변경해 직접 닫기 전까지 유지
크기 조절 손잡이가 동작하지 않음독립 창의 기본 크기 조절 사용, 손잡이 코드 제거
사이드 패널이 화면을 가림 / 일부 브라우저에서 오류사이드 패널을 제거했다가, 이번에 설정 선택지로 복원(미지원 브라우저는 비활성)
저장한 직후 팝업을 열면 없는 경우저장 우선(OG 이미지는 나중에), 저장 순서 보장 큐, 열려 있는 창 자동 갱신
달력 열면 아무 글도 안 보임오늘 날짜 자동 선택, 하단 요약(문장·페이지 수) 추가
달력 점 표시는 개수를 알 수 없음날짜 아래 저장 개수 숫자로 변경
"내 문장 모음" 이름이 어색함"밑줄 노트"로 확정, 헤더 제목 "전체 / 사이트명 / 달력"
필터 해제가 번거로움필터 1개 이상일 때 초기화 버튼
My 로고를 눌러도 반응 없음My 로고 = 전체 목록으로 복귀
저장됐는지 알 수 없음웹페이지 위 저장 성공/실패 토스트
저작권·문의 경로가 없음하단 바에 저작권 문구, E-mail 문의(메일 작성), 제작자 블로그(새 탭) 링크 추가
"빈 상태" 화면이 시안과 다름시안대로 아이콘 + 제목 + 안내 문구를 가운데 정렬로 적용
버전·설정 버튼 위치가 떠 있는 느낌화면 아래 가로로 긴 하단 바로 분리
표시 방식 이름만으로는 차이를 알기 어려움항목 오른쪽 끝에 모양 아이콘 그림 + "별도 저장 없이 바로 적용" 안내
시안이 다크 배경이라 문서·공유에 불리시안과 앱을 모두 화이트 배경으로 변경
화면 지칭이 불명확화면명세 번호 부여(ma01 등)
현재 버전을 알 수 없음오른쪽 아래 버전 표시(manifest 값 자동 반영)

  • 저장 데이터는 이 브라우저에만 있습니다(기기 간 동기화 없음).
